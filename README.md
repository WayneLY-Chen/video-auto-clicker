# 滑鼠連點器：影片定時播放／暫停

市面上的連點器大多只能「每隔幾秒點一下」。這個工具可以分開設定**播放多久**和**暫停多久**，自動循環：

```
播放 10 分鐘 → 點一下（暫停）→ 等 2 秒 → 點一下（播放）→ 播放 10 分鐘 → …
```

只支援 Windows。

## 下載

到右邊的 [**Releases**](../../releases) 下載最新的 `.exe`，點兩下就能用，不用安裝 Python。

> 第一次打開時，Windows 可能會跳出「Windows 已保護您的電腦」。這是因為 exe 沒有數位簽章，按 **其他資訊 → 仍要執行** 就可以。

## 使用方式

1. 打開影片，**先讓它開始播放**。
2. 設定點擊位置（三種方法都可以）：
   - **點一下選位置**：畫面會變暗，在播放／暫停鈕上點一下就記好了。這一下不會真的點到影片。按 Esc 或右鍵取消。
   - **3秒後選位置**：按下後 3 秒內把滑鼠移到播放／暫停鈕上。
   - **F8**：滑鼠停在按鈕上時直接按 F8。
3. 設定播放時間、暫停時間、重複幾輪。
4. 按 **開始** 或 **F6**。

## 設定說明

| 項目 | 說明 |
|---|---|
| 動作方式 | 「滑鼠左鍵點擊指定位置」或「按空白鍵」。大部分網站（例如 YouTube）按空白鍵就能播放／暫停，用這個就不用設位置，但瀏覽器要在最前面。 |
| 播放多久後暫停 | 時／分／秒 |
| 暫停多久後繼續 | 秒，最少 1 秒（太短會被播放器當成連點兩下，變成全螢幕） |
| 重複幾輪 | 0 = 無限重複 |
| 點完把滑鼠移回原位 | 點完後滑鼠回到原本的位置 |
| 視窗永遠在最上層 | 讓連點器視窗不會被瀏覽器蓋住 |

## 快捷鍵

連點器視窗不在最前面也能用。

| 按鍵 | 功能 |
|---|---|
| F6 | 開始／停止 |
| F8 | 記錄目前滑鼠位置為點擊位置 |

## 小技巧

- 全螢幕時播放鈕通常會藏起來。大部分網站點影片中間也能播放／暫停，所以位置可以設在畫面中間。
- 先按「測試點一下」，確認有點到對的位置。
- 設定會自動存在程式旁邊的 `settings.json`，下次打開會自動載入。

## 自己打包成 exe

在另一台電腦拿到原始碼（`滑鼠連點器.pyw`）後，想自己做成 exe：

1. 安裝 [Python](https://www.python.org/downloads/)。安裝時勾選 **Add python.exe to PATH**，其他用預設就好（預設會裝 tkinter 和 `py` 啟動器）。
2. 把這個專案下載下來：按綠色的 **Code → Download ZIP** 再解壓縮，或用 `git clone`。
3. 點兩下 **`build.bat`**。它會自動安裝 PyInstaller 並打包，完成後 `滑鼠連點器.exe` 就會出現在同一個資料夾。

只想直接執行、不打包的話，裝好 Python 後點兩下 `滑鼠連點器.pyw` 就能用。

### 換圖示

把圖示檔命名成 **`icon.ico`**，放在 `build.bat` 旁邊，再跑一次 `build.bat`。exe 的檔案圖示和視窗左上角的圖示都會換掉。

- 一定要是 `.ico` 格式。PNG 可以先用線上工具（搜尋「png to ico」）轉檔。
- 換完後如果檔案總管還是顯示舊圖示，是 Windows 圖示快取的關係，把 exe 改個名或重開機就會更新。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `滑鼠連點器.pyw` | 主程式（只用 Python 內建模組） |
| `build.bat` / `build.py` | 一鍵打包成 exe |
| `icon.ico` | （選用）自訂圖示 |
